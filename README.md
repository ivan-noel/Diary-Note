# Diary Note

A simple and modern desktop diary application built with Electron.

## 📥 Download

<a href="https://github.com/ivan-noel/Diary-Note/releases/tag/v1.0.0">⬇️ Download Diary Note</a>

Download the latest Windows installer from the official GitHub Release page.

## ✨ Features

* 📝 Create and manage diary notes
* 🎨 Customizable application interface
* 🖼️ Custom wallpaper support
* 💾 Local note storage
* 🖥️ Windows desktop application
* ⚡ Lightweight and fast

## 🛠️ Built With

* HTML
* CSS
* JavaScript
* Electron
* Node.js

## 📦 Installation

### For Users

1. Download **Diary Note Setup 1.0.0.exe** from the [Release](https://github.com/ivan-noel/Diary-Note/releases/tag/v1.0.0).
2. Run the installer.
3. Follow the installation instructions.
4. Launch **Diary Note**.

### For Developers

Clone the repository:

```bash
git clone https://github.com/ivan-noel/Diary-Note.git
```

Open the project folder:

```bash
cd Diary-Note
```

Install dependencies:

```bash
npm install
```

Run the application:

```bash
npm start
```

## 🔨 Build the Application

To create the Windows installer:

```bash
npm run dist
```

The installer will be generated inside the `dist` folder.
